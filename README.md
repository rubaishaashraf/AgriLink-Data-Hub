# 🌱 AgriPulse - Sustainable Farming Through Smart Insights

## 📌 Description
AgriLink Data Hub is a Flask-based web application that manages data of farmers, crops, fertilizers, and production in one system.

---

## 🚀 Features
- Manage farmers data
- Track crops
- Manage fertilizers
- Record production

---

## 🛠️ Technologies
- Python (Flask)
- MySQL
- HTML, CSS

---

## ⚙️ Setup Steps

1. Install requirements  
   pip install -r requirements.txt
   pip install flask mysql-connector-python

3. Create database  
   agrilink_db  

4. Import database file  
   agrilink_db.sql  

5. Update config file  
   app/config.py  

---

## ▶️ Run Project
python run.py  

Open browser:  
http://127.0.0.1:5000/  

---

## ⚠️ Note
- Add your own database password in config.py  
- Do not upload real credentials
